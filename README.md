processa.qar é o projeto final da disciplina lab de sistemas operacionais acrescido de um modulo uart para comunicação externa.

interface_pt e central_mensagens são dois arquivos da interface de controle do sistema. o primeiro é a interface e o segundo controla ela

msg_center é o arquivo arduino responsavel por fazer a conexão entre o computador (controle do fpga por um computador) e o fpga
